# Ассоль — салон красоты в Липецке

Просмотр сайта: https://volodin-maksim.github.io/assol-salon-lipetsk/

Статический сайт для просмотра и оценки клиентом: HTML, CSS, JavaScript, адаптивные WebP, локальные шрифты и 3D-ножницы Three.js. Включены исправления центрирования на Retina и автоматическая смена отзывов.

## Публикация

1. Создайте репозиторий `assol-salon-lipetsk` в GitHub и загрузите содержимое этой папки в ветку `main`.
2. В **Settings → Pages → Source** выберите **GitHub Actions**.
3. Запустите workflow **Deploy Assol to GitHub Pages**. Он автоматически запускается и при push в `main`.
4. Готовая ссылка появится в Environment **github-pages** после успешного deploy.

Страница, изображения, шрифты, форма и ES-модули используют относительные пути, поэтому работают по адресу `https://OWNER.github.io/REPOSITORY/`. Workflow самостоятельно задаёт canonical и Open Graph под адрес Pages. Для клиентского просмотра сохранён `noindex`.

## Локальный просмотр

`python -m http.server 8000 --directory site`, затем `http://localhost:8000`.

## Запись

Интерфейс выбора услуги, мастера, даты, времени и контактов готов. Отправка выключена, пока владелец не включит анонимный доступ к своему Apps Script. Значение `endpoint` в `site/booking-config.json` намеренно пустое. Успех не имитируется.

## Материалы и данные

Главный портрет предоставлен пользователем и обработан. Интерьер и коллекция образов — AI-иллюстрации. Контакты, цены и выдержки из отзывов взяты из карточки салона на Яндекс Картах. Подробнее — `site/case.html` и `site/salon-data.json`. Лицензия на чужие бренды и материалы не заявляется.

Backend Google Sheets, идентификатор приватной таблицы, настройки доступа Sites и история внутреннего репозитория в этот экспорт не включены.
